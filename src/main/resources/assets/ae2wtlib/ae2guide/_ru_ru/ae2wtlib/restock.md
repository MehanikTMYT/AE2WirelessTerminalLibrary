# Автопополнение

При включённом автопополнении <ItemLink id="ae2:wireless_crafting_terminal" /> пытается восполнять использованные предметы из МЭ-системы.

Функция включается в интерфейсе или горячей клавишей.

Автопополнение поддерживает максимальный размер используемой стопки — 64
для большинства предметов. Недостающие предметы берутся из МЭ-системы,
а излишки при подборе отправляются обратно. Поэтому если
поставить несколько блоков и затем сломать их, предметы
не займут другой слот, даже без активной <ItemLink id="ae2wtlib:magnet_card" />.

Стопки, в которых до использования был только один предмет, **НЕ** пополняются.

Также изменяется отображаемое количество предметов на панели быстрого доступа: оно
показывает запас в сети (+ предметы, которые действительно находятся на панели).

Функция работает только в радиусе точки
доступа или при [квантовой привязке](quantum_bridge_card.md) терминала.

В творческом режиме она автоматически отключается, поскольку предметы всё равно не расходуются.

Автопополнение работает для большинства действий: установки блоков, приёма пищи, стрельбы из лука. Другие действия,
особенно из сторонних модов, могут не распознаваться — тогда использованные предметы не пополняются.
