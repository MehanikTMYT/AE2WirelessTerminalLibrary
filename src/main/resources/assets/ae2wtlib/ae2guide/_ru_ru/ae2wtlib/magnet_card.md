# Магнитная карта

<ItemImage id="ae2wtlib:magnet_card" scale="3" />

<ItemLink id="ae2wtlib:magnet_card" /> — [карта улучшения](ae2:items-blocks-machines/upgrade_cards.md) для <ItemLink id="ae2:wireless_crafting_terminal" />. Она добавляет <ItemLink id="ae2:wireless_crafting_terminal" />
магнит, который можно включать и настраивать фильтрами в
интерфейсе. Для включения и выключения также есть горячая клавиша.

<ItemLink id="ae2wtlib:magnet_card" /> выполняет две функции:

1. Подбирает предметы в увеличенном радиусе (настраивается, по умолчанию 16)
2. Помещает подобранные предметы в МЭ-систему вместо инвентаря

Обе функции включаются и фильтруются независимо друг от друга: есть фильтр подбора
и фильтр вставки. Для каждого можно выбрать режим чёрного или белого списка.
