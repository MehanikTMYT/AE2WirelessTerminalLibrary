# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />


Беспроводные терминалы — портативные версии обычных проводных [терминалов](terminals.md). Интерфейсы у них такие
же, но вместо слотов для <ItemLink id="view_cell" /> предусмотрены слоты для [карт улучшений](upgrade_cards.md)

Для привязки к сети нужно вставить терминал в верхний правый слот <ItemLink id="wireless_access_point" />, подключённой
к этой сети. Это слот с изображением беспроводного терминала и стрелкой под ним.

Для работы нужно находиться в радиусе действия <ItemLink id="wireless_access_point" />.

Зарядить их можно в <ItemLink id="charger" />.

# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />

Обычный терминал теперь можно носить с собой! Просматривайте
[хранилище сети](../ae2-mechanics/import-export-storage.md), работайте с его содержимым и отправляйте
запросы [автокрафта](../ae2-mechanics/autocrafting.md) из любой точки в радиусе действия <ItemLink id="wireless_access_point" />.
